---
name: SOP page model
description: User requirements for publishing the Google Docs SOP tabs on the public site.
---

Each source document tab must remain an independently addressable standalone page. Do not replace the pages with a shared dynamic guide reader. The converted page files should not remain in App Storage.

**Why:** The user explicitly requested separate pages per tab and asked for the converted document to be erased from App Storage after completion.

**How to apply:** Keep a section index that links to individual pages. If refreshing or restructuring the imported SOP, preserve separate page routes and do not upload the converted exports back to App Storage without explicit direction.
