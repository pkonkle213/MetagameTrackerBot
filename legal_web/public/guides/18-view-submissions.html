View Submissions

Permissions Needed - Owner or MTSubmitter

From time to time, you’ll want to check archetypes submitted based upon a specific date of event or the player’s name. Use the /viewsubmissions command to get a report of archetypes submitted.

  1. Use the /viewsubmissions command to launch the report
  2. This command has two optional names: player_name and event_date
  3. If sent without these, the command will print the last 15 (due to all the text involved)(Note: all names and user ids have been blanked out)
  4. If event_date is provided, the report will filter to just that event
  5. If player_name is provided, the report will filter to just that person
  6. If both are filled in, the report will filter to both
