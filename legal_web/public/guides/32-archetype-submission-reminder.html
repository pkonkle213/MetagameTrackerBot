Archetype Submission Reminder

For each guild, my bot will go through all events that are exactly 3 days old. The main goal is to close all events and to see if they’re fully submitted.

If archetypes are missing, the bot will use the category and channel mappings to determine the best channel to ask for submissions, then present the date of the past event as well as the names for which archetypes haven’t been submitted.
