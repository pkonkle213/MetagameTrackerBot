All League commands are reserved for paid stores only

  • What is a league?
  • I define a league by a group of events that have a set timeframe for a beginning and an end
  • How is a leaderboard achieved?
  • Currently, the only system for a leader board is to compare accumulated points earned in an event and a player’s win percentage over that event. Each round win gets a player 3 points, each round draw gets them 1 point, and each loss gets them 0 points.
