Initial Setup

Permissions needed - Owner

Complete this list of actions to set up the bot and be ready for data:

  1. Join my bot’s Discord server. You can find the server with this invite: https://discord.gg/bE6qMXQHru.
  1. In the bot’s Discord, you’ll find two public channels: #general and #updates. Please use the #general channel to talk with other users as well as me. In the #updates channel you’ll find my official updates outlining changes to the bot, ideas I’ve had, and plans for the future.
  2. There is a third less-public channel called #store-feedback-and-requests. This is for store owners only. Please use this channel to report any specific feedback about the bot or any requests for what you’d like to see from the bot. Ideas and feedback shared in this channel will be prioritized over ones in the #general channel
  1. Use the two slash commands in the #general channel to find out more information:
  1. /getbot provides the link to integrate my bot with your discord
  2. /getsop provides the link to review this SOP

There are also two pinned messages with the same information.

  1. When the bot is installed to your server, it checks your categories and channels to see if your discord has them set up to reflect the exact names of games and formats. If so, the bot will automatically map them and alert the user to the mappings it has chosen. If not, it will alert the owner to map them manually.
  2. Create and assign the MTSubmitter role as needed
  3. Use /map game to instruct the bot on which group of channels are certain games like Magic, Lorcana, etc.
  4. Use /map format to map a specific format to your channel
  5. Use /update to update the store’s profile including the owner’s preferred name, store name, store address, Melee.gg client ID and client Secret (more on that later), and more!
