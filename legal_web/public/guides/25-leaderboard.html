Leaderboard

Permissions Required - Everyone

Use the /topplayers command to see the store’s top players for a date range and game. The format is optional, so this command can be used in a non-format-mapped channel to get a bigger pool of results.

Steps

  1. Type /leaderboard into the message
  2. This command has two optional fields: start_date and end_date
  1. If end_date isn’t entered, it’s assumed to be today
  2. If start_date isn’t entered, it’s assumed to be 8 weeks before end_date or the date when an update affected this format (banning or rotation)
  1. The bot will communicate that it’s calculating, then replace that message with the top players. The quantity of players is based on half of the average attendance of the events. So if a format brings in an average of 8 people, you’ll see a leaderboard of 4. Players are displayed based upon their number of points earned in the date range (3 points per win, 1 point per draw) and then their win percentage

(Source: MTGO Challenge Data)
