Mapping Games

Permissions Required - MTStore or owner

The bot recognizes categories as the names of the game and channels as the format names (if the game uses them). To start tracking data, you’ll need to instruct the bot which category is which game. The command /map game will prompt you to select one of the games I support.

To map the game’s category, choose any channel in the game’s category. In this example, I’m choosing the General channel in my Gathering of Magics category, but I could have chosen Legacy or Pauper.

Type /map game as a message

Send that command, and the bot will present you with a dropdown list of supported games.

For this category, I want to map this to “Magic”, so I click “Magic” and then “Submit”

When the category is mapped, you’ll receive this message:

Now the bot will recognize data input as well as any requests to be for the game of Magic. You’re free to change the name of this category at any time, as the ID of the category is now linked to the game of your choice. If you map a second category to any game, this will overwrite the previous mapping.
