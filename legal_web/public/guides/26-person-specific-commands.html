Person Specific Commands

These commands are player specific and the bot needs to know who the user is. It achieves this by recognizing users from their Archetype Submissions. The bot will look to see what name is most reported by the user. If a player desires these statistics, they need only be 1 submission for the correct name more than anyone else. If a player doesn’t need these, there’s no need to worry about this!

As an example, we’ll use my name, Phillip Konkle, and we’ll guess my DiscordID is 1234. If my first submission is for “Phillip Konkle”, the bot will assume that any request for data from user 1234 is looking for “Phillip Konkle” data. In later weeks, if I submit for myself, Joe Smith, and Jane Hopper, the bot will see 2 submissions for “Phillip Konkle”, 1 for “Joe Smith”, and 1 for “Jane Hopper”. The bot will then assume for later requests from user 1234 that it should be looking for “Phillip Konkle”. If I later only submit an archetype for “Jane Hopper”, the bot will become confused and guess which name is used for user 1234. I would need to submit another archetype for myself.
