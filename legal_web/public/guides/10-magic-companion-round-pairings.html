Magic - Companion - Round Pairings

Permissions Required - MTSubmitter or owner

The bot recognizes data taken from Companion/Eventlink. During or at the end of your tournament, copy all of the round results starting before rank 1 and going all the way to the last person’s record or ‘BYE’. You’ll need this to enter into the modal screen that pops up. This prevents unwanted attention brought upon specific players. The bot will either create a new event specific to the date provided or supplement the event from the same format and day. It will send a message that it is inputting the data, and when it has completed saving the bot will privately send another confirming that all the results were added. It will also publicly announce that data has been entered and players will then need to be encouraged to submit their deck’s archetype name by using the /submit archetype command.

  • Go to Companion/EventLink and view the pairings for the round. Highlight all information in the red box and copy it.

  • Back in your Discord, use the /submit data command in the format you’re submitting.
  • Hit [Enter] to send this and you’ll receive a modal for the event details
  • If this is the first time you’re submitting data for this format today…
  • The bot will assume you’re creating a new event. You’ll want to input the event’s date, the event’s name, and whether the event was a weekly (regular) event, a tournament (competitive), or a league (a group of weekly events), as well as the copied data from eventlink.
  • If not, select the event you want to submit data for from the top dropdown
  • For the “How will data be submitted?” dropdown, you’ll want to select “Manual”.
  • The bot will present the event details to you to ensure their accuracy. Press [Continue] if everything is correct

  • The bot will then present you with a modal to paste the text you copied from EventLink and select [Submit]

  • The bot will then advise you of the data that was input so you can ensure its accuracy. Specific pairings of names and round numbers cannot be duplicated throughout the event.

  • Select [Cancel] if the information is incorrect
  • Select [Continue] if the information is correct and you’re ready to submit the next round
  • Select [Done, Event Complete] if you’re done submitting data for the event and the event is over.
  • Select [Done, Event Incomplete] if you’re done submitting data for the event but the event isn’t over. This will prevent archetypes and results from being published mid-event
  • Once you select one of the [Done] options, the bot will publicly announce that new data has been added and people can start using the /submit archetype command
