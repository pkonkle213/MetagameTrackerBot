Downloading Player Data

Permissions Required - Everybody

I figured some players might like to do their own analysis of their data. Using this command, you’ll be sent up to two CSVs with the data that I have.

  1. Find the /download player command

  1. This command has two optional fields: start_date and end_date

  1. If end_date isn’t entered, it’s assumed to be today
  2. If start_date isn’t entered, it’s assumed to be 8 weeks before end_date or the date when a ban affected this format (if used in a channel mapped to a format)
  1. The bot will privately message you up to two CSVs, depending on how the store has reported data
