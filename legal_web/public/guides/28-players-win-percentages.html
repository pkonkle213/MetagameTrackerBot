Players’ Win Percentages

Permissions Required - Everybody

With enough submissions, the bot will be able to associate a user id with a player’s name at the store. With the /personal_stats wlrecord command, the bot will advise the user of their win/loss/records. This includes both an overall win percentage as well as a breakdown per archetype.

  1. Find the /personal_stats wlrecord command

  1. This command has two optional fields: start_date and end_date

  1. If end_date isn’t entered, it’s assumed to be today
  2. If start_date isn’t entered, it’s assumed to be 8 weeks before end_date or the date when a ban affected this format
  1. The bot will assume that the user is looking for results for a name associated with the user id
