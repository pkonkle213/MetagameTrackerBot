When you submit archetypes, the bot tracks your discord user id and the name you’re submitting for. It will assume that your name is the person you submit the most archetypes for.

For example:

My name is Phillip Konkle and my discord id is 12345.

For my first event, I submit my own archetype.

Archetype Submissions

Name

1

Phillip Konkle

Result:

The bot assumes that user 12345’s name is Phillip Konkle.

The next event I attend, I submit my own archetype as well as my friend, John Doe.

Archetype Submissions

Name

2

Phillip Konkle

1

John Doe

Result:

The bot assumes that user 12345’s name is Phillip Konkle.

I don’t attend the event the next week, but John asks me to submit his archetype

Archetype Submissions

Name

2

Phillip Konkle

2

John Doe

Result:

The bot does not know what user 12345’s name is and may give either name as an answer.
