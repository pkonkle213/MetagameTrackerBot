Get User Info - Context Command

Permissions Required - Everyone

This command is an exception to the rule, as you find this command by right clicking another user’s profile picture or name. Under the “Apps” menu, you’ll see “Get User Info”. If this person has submitted their archetype, you’ll see their name, the last played deck in the format you’re currently in and the date, and you’ll see their top 3 decks with a percentage of how often they play them.

To use this command on the computer:

  1. Find the user you’d like to see their info and right click on their name
  2. Under “Apps”, find “Get User Info” and left click
  3. Using the category you’re in as the game and the channel as the format, MetaTracker will display a message with the user’s name, last played deck, and top 3 popular decks with their play rate (not their win rate)

To use this command on the phone:

  1. Press and hold the users name until their menu pops up. Select the 3 dots in the top right corner
  2. Select “Apps”
  3. Select “Send”
