Players Submitting Archetypes

Permissions Required - Everyone

  • Players need to use the /submit archetype command to enter their archetype name. The player’s name must exactly match the name entered into Companion (it must match the name in the database) and the date of the event needs to be provided

How to submit an archetype:

  • Type /submit archetype into the message bar and select the command
  • Using the pop up that appears, fill in the appropriate information
  • Select the event the player was in. The menu will automatically select the last one chronologically. Those with the MTSubmitter role will see the past 8 weeks of events, while those without the role will only see the past 2 weeks
  • The user needs to input the name of the player spelled exactly as it was registered in the event. This field defaults what the bot assumes the user’s name it, but can be adjusted
  1. If the user forgets how the name was registered, they can use the /unknown command to view all names that haven’t added an archetype
  • To submit an archetype, one of the following needs to be done
  1. If this is one of the current user’s most played decks, the archetype will be in the dropdown, sorted by the most played first and then descending
  2. If the archetype isn’t one of these, the user will have to manually input the archetype
  3. If both of these are done, the archetype selected will override the manual archetype
  • If the name is not found in the event, the bot message this following error:

  • If the name was found in the event, the archetype will be updated and the user notified privately

If a user accidentally submits the wrong archetype, such as a typo, simply have the user resend their submission. The bot will use the last entered information.

  • If this submission puts the event past a 25%, 50%, or 75% threshold, the bot will congratulate the format for submitting data and encourage more submissions
  • If this submission puts the event at the 100%, the bot will out all archetype names submitted and the wins for each.
  • If there is an inappropriate word/phrase in the archetype, please see the ‘Dealing With Offensive Words’ tabs
