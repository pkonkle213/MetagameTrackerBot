CARDE.IO - Round Pairings

Permissions Required - MTSubmitter or owner

Carde.IO currently supports Riftbound as well as Lorcana events. They provide a CSV to import into the bot. Exporting the CSV is simple.

  1. Select the three dots at the top right of the pairings and select ‘Export to CSV’
  2. Back in discord, use the command /submit data 
  3. Select the csv_file optional parameter
  4. From here, you can drag and drop the file into discord or you can click the upload area to find your file and upload it
  5. Once the file is loaded, hit [Enter] to send the command
  6. A modal will pop up to confirm event details such as the date, name, and type. Or you can select from one of the previous events to continue submitting pairings for it.
  7. The bot will privately confirm the number of pairings in the file.
  8. Once the upload is complete, the bot will privately confirm the number of pairings uploaded and publicly announce that new data has been submitted if this is the first data uploaded for this event
  1. Note: the bot will assume that the data is for today. I have yet to identify if the date of the event lives within any data of the uploaded file.
