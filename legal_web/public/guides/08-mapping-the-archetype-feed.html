Mapping the Archetype Feed

Permissions Required - MTStore or owner

Stores have the option to set up their own feed so that they can see what people are claiming and for whom. To do this, you’ll need to set up a private channel in the game, add the bot as a member of said channel, map the channel, and then the bot will do the rest!!

  1. Create a private channel
  2. Name it whatever you’d like, and mark it as private if you’d like
  3. Select ‘Next’ or ‘Create Channel’
  1. If you selected to make it private, make sure to select MetaTracker under Members and select “Create Channel”
  1. With the channel created, use the /map claimfeed command to let the bot know the purpose of this channel
  2. Once sent, the bot will alert you that the mapping has been successful
  3. Once the channel has been mapped, all attempts to use the /submit archetype will feed into this channel. You’ll see any error that’s related as well as successful additions. This will give a look into what is being submitted, for what person, and where.
