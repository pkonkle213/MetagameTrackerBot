Viewing Metagame Data

Permissions Required - Everyone

Use the /metagame command to view your game and format’s metagame data!

Steps:

  1. Type /metagame into the message bar
  2. The game and format are assumed based upon the category and channel the request comes from and how the channel is mapped. The command has two optional inputs: start_date and end_date
  1. If end_date isn’t entered, it’s assumed to be today
  2. If start_date isn’t entered, it’s assumed to be 8 weeks before end_date, or the last time a ban or rotation affected the format
  1. The bot will display that it is calculating, then will replace that message with a table of the metagame

    Only decks that make up 2% or more of the metagame are displayed. This is to prevent one-off submissions of deck names. They’re ordered first by “Meta %”, then “Win %”, and then alphabetically.
  2. If there is an inappropriate word/phrase in an archetype, please see the ‘Dealing With Offensive Words’ tab on how to deal with it
