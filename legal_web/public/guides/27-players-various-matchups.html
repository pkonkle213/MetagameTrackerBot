Players’ Various Matchups

Permissions required - General

This command requires the store to submit pairings data. If standings data is submitted, it will not be reflected in this command

To view your matchups versus other decks, use the /personal_stats matchups. This will print out a specific breakdown of archetypes the user has played against in a format.

  1. Select the /personal_stats matchups command:
  2. This command has two optional fields: start_date and end_date.
  1. If end_date isn’t entered, it’s assumed to be today
  2. If start_date isn’t entered, it’s assumed to be 8 weeks before end_date or the date when a ban affected this format
  1. The bot will print out a view of decks that the user has played and their matchups against the metagame. The decks the user plays will be in order of their rate of play, and the metagame will be sorted by their metagame share.
