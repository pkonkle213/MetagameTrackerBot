Attendance

Permissions Required - Everyone

Use the /attendance command for a quick look at the attendance for a date range.

Steps

  1. Type /attendance in the message field
  2. This command has two optional fields: start_date and end_date
  1. If end_date isn’t entered, it’s assumed to be today
  2. If start_date isn’t entered, it’s assumed to be 8 weeks before end_date or the date when a ban affected this format
  1. The game, format, and or region are assumed based upon the category and channel the request comes from.
  2. The bot will message that it is thinking and then will replace that message with a table of the dates of the most recent events as well as their attendance.
  1. This data is sorted descending by date
  2. If this command is used in a hub, this will include the store name
